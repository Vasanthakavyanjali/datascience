# House Price Prediction - End-to-End MLOps

## Project Overview

This project implements an end-to-end MLOps
pipeline for predicting house prices using
Machine Learning.

## Technologies

- Python
- Scikit-learn
- Git and GitHub
- DVC
- DAGsHub
- MLflow
- Docker
- FastAPI
- Streamlit
- AWS EC2
- AWS ECR

## Dataset

California Housing Dataset.

## Machine Learning Algorithm

Random Forest Regression.

## Workflow

1. Data collection
2. Data preprocessing
3. Model training
4. Model evaluation
5. DVC pipeline tracking
6. DAGsHub experiment tracking
7. FastAPI deployment
8. Streamlit frontend
9. Docker containerization
10. AWS cloud deployment

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R2 Score

## Application

FastAPI provides the prediction endpoint.

Streamlit provides the user interface.

## Deployment

The application is containerized using Docker
and deployed using AWS EC2 and AWS ECR.
